# DS&A Lab — データ構造とアルゴリズム 学習ラボ

関西学院大学「データ構造とアルゴリズム」（作元 雄輔 先生）の講義内容を、**動かして・触って・直感で理解する**ための非公式インタラクティブ学習サイト。講義資料が届くたびに 1 回分ずつ拡張していく。

## デザインコンセプト — "Playground"（v2・可愛い系）
- クリーム色のドット紙＋インク色（#3d2e54）の太い輪郭線＋ステッカー風のずらし影。フォントは Fredoka（英数）/ Zen Maru Gothic（和文）
- 色は**意味**を持つ（全ラボ共通）: オレンジ = いま注目（ポインタ）、空色 = 訪問済み、ミント = 発見・正解、ピンク = 削除・失敗。各回はテーマ色（ピーチ/空色/ミント/ラベンダー）
- ヒーロー: 15 個のキャンディ玉が「配列 → スタック → 循環キュー → 2分木 → グラフ」に変形し、顔つきのポインタ玉が辺を辿る
- キャラクター: `lib/chars.js` の SVG アバター（サカイ=眼鏡＋ボブ、リョウガ=つんつん頭）。台詞内容から表情（normal/happy/think/oops/wow）を自動推定、`S[happy]: …` で明示も可
- 類題: 正解で紙吹雪、解説はサカイの吹き出し（正解=ミント／不正解=ピンク）
- **対話形式**: 本文は **サカイ（先輩・解説役／琥珀・左）** と **リョウガ（受講生・質問役／シアン・右）** の会話で進む。類題の解説もサカイの吹き出しで表示
- 各章は「対話 → 可視化ラボ → 対話 → POINT（ここだけ押さえる）」、各回の最後に類題。全ラボは ← → / Space でステップ再生

## モーション / インフォグラフィック（v3）
- **Kinetic Typography**（`lib/motion.js`）: 見出しを 1 文字ずつ分解（`splitText`）し、画面に入ると弾んで出現。ヒーロー見出しはカーソルに反応して文字が浮き上がる（`reactiveType`）。単語が回転で入れ替わる（`rotateWord`）、数字のカウントアップ（`countUp` / `data-count`）、記号スクランブル（`data-scramble`）
- **UI アニメーション**: カスタムカーソル、マグネットボタン、3D チルト＋光沢、クリック波紋、値が変わると弾む（stat / score）、ページ遷移の 4 色カーテン、章の進捗レール（右端）、スクロール速度連動のマーキー、会話の吹き出しがワイプで出現
- **インフォグラフィック**（`pages/infographics.js`）:
  - ホーム「n が増えると、何が起きる？」— スクロールで n = 10 → 100 万。6 つのオーダーの操作回数・所要時間が伸び、2ⁿ は燃える
  - ホーム「いま、ここまで」— 講義・章・ラボ・類題数のカウントアップ
  - 各回ヒーロー — 章／ラボ／セリフ／類題の数と、サカイ：リョウガの会話比率ドーナツ
  - 計算量表 — 成長曲線が描画される折れ線グラフ（ホバーで強調）＋順序チェーン
- `prefers-reduced-motion` ではすべて静止表示に切り替わる

## 実装済みの内容
| 回 | テーマ | 主なラボ |
|---|---|---|
| 1 | 計算とアルゴリズム | 互除法ステッパ（長方形タイル＋行ごと実行回数）、線形探索の操作回数カウンタ、最悪/平均/最良の比較、部分和 2ⁿ グリッド、指数爆発 |
| 2 | 漸近記法 O・Ω・Θ | c と n₀ を探す境界エクスプローラ、集合包含図、性質 A/B ステッパ、増加レース、増加表、フィボナッチ再帰木 |
| 3 | リスト・スタック・待ち行列 | 配列リスト vs 連結リスト同時実行、スタック、再帰=スタック、循環キュー（輪＋直線）、操作列シミュレータ |
| 4 | グラフ・木・2分木 | 3 表現（隣接行列/配列リスト改/連結リスト）切替エディタ、BFS 最短路、根付き木の用語エクスプローラ、木の BFS、前・中・後順のオイラー巡回、前順＋中順からの復元、路・閉路エクスプローラ（単純閉路の全列挙・最長閉路・歩いて分類） |

共通: 計算量表（`#/cheatsheet`）、用語集（`#/glossary`）、⌘K / `/` クイック検索、達成目標チェック・類題正答の保存（localStorage）。

類題は講義内容から作成したオリジナル問題（課題レポートの問題そのものではない）。

## URL / ルート
- `/#/` ホーム ・ `/#/lecture/:n` 各回 ・ `/#/lecture/:n?a=<章ID>` 章へ直接 ・ `/#/cheatsheet` ・ `/#/glossary`

## 講義の追加方法（次回以降）
1. `public/static/js/lectures/lecNN.js` を作成（既存回と同じ形: `n, title, sub, en, tags, goals, chapters[{id,k,title,build}], quiz[]`）
2. `public/static/js/lectures/index.js` で import して `LECTURES` に追加、`UPCOMING` を更新
3. 用語を `public/static/js/data/glossary.js`、計算量を `pages/cheatsheet.js` に追記
4. 章の本文は対話で書く:
   ```js
   build(el) {
     el.append(
       talk(`R: 質問（リョウガ）
   S: 解説（サカイ）。HTML・$数式$ 可。続く行は改行として連結`),
       lab(...),            // 可視化
       point('章の要点 1〜2 文'))
   }
   ```
- 部品: `lib/ui.js`（talk, point, lab, Player, stat, callout, table, formula…）、`lib/viz.js`（グラフ/木レイアウト）、`lib/code.js`（C コードビューア）、`lib/quiz.js`

## 技術構成
- Hono（Cloudflare Pages）で HTML シェルを配信、フロントは素の ES Modules（ビルド不要）
- KaTeX（数式）、Google Fonts（Space Grotesk / Zen Kaku Gothic New / JetBrains Mono）
- データ保存: ブラウザ localStorage のみ（サーバ DB なし）

## 開発
```bash
npm run build && pm2 start ecosystem.config.cjs   # http://localhost:3000
```
